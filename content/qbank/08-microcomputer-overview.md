> 本章覆盖微型计算机原理的基础知识：冯·诺依曼结构、8086 CPU组成、存储器分类、I/O编址等。所有题目均附详细解答。

### Q121：什么是微型计算机？它由哪几个部分组成？

**🔑 答案**：

微型计算机是以微处理器（CPU）为核心，配以存储器、I/O接口电路和系统总线构成的计算机系统。

| 组成部分 | 功能 |
|---------|------|
| 微处理器（CPU） | 执行指令、进行运算和逻辑判断 |
| 存储器 | 存放程序和数据 |
| I/O接口电路 | CPU与外部设备之间的桥梁 |
| 系统总线 | 连接各部件的公共通信通道（地址、数据、控制） |

---

### Q123：冯·诺依曼结构计算机的基本思想是什么？

**🔑 答案**：

**存储程序原理**——程序和数据预先存放在存储器中，计算机自动、顺序地取出指令并执行。

五大部件：运算器、控制器、存储器、输入设备、输出设备。

### Q127：存储器按存取方式可以分为哪几类？

**🔑 答案**：

| 类型 | 特点 |
|------|------|
| RAM（随机存取） | 可读可写，断电丢失，速度快（SRAM/DRAM） |
| ROM（只读） | 只能读不能写，断电保持，存放固定程序（PROM/EPROM/EEPROM/Flash） |
| NVRAM | 非易失RAM，断电保持数据 |

### Q131：8086 CPU由哪两个部分构成？各自功能是什么？

**🔑 答案**：

- **BIU（总线接口单元）**：取指令、读/写存储器和I/O端口数据。内含指令队列（6字节），实现**指令预取**。
- **EU（执行单元）**：译码并执行指令，完成算术逻辑运算。

二者**并行流水线工作**——BIU提前取指令放入指令队列，EU从队列中取指令执行，显著提高CPU效率。

### Q133：二进制、十进制、十六进制之间的换算

**🔑 答案**：

- 二进制→十进制：\(1010_2 = 1\times 2^3 + 0\times 2^2 + 1\times 2^1 + 0\times 2^0 = 10\)
- 十进制→十六进制：\(47_{10} = 2\times 16 + 15 = 2F_{16}\)（F=15）
- 十六进制→二进制：每组4位，\(3A_{16} = 0011\ 1010_2\)

### 本章小结

微型计算机以CPU为核心，遵循冯·诺依曼存储程序原理。8086分为BIU+EU双单元并行工作。存储器分为RAM/ROM等类型。总线（地址/数据/控制）是信息传输通道。
