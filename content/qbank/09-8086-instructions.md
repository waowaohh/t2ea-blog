> 本章聚焦8086 CPU的寻址方式、指令系统、标志寄存器和段式内存管理机制。

### Q147：8086有哪些寻址方式？举例说明

**🔑 答案**：

| 寻址方式 | 示例 | 有效地址（EA） |
|---------|------|---------------|
| 立即寻址 | `MOV AX, 1234H` | 操作数在指令中 |
| 寄存器寻址 | `MOV AX, BX` | 操作数在寄存器 |
| 直接寻址 | `MOV AX, [2000H]` | EA = 2000H |
| 寄存器间接 | `MOV AX, [BX]` | EA = BX |
| 基址寻址 | `MOV AX, [BX+10H]` | EA = BX + 10H |
| 变址寻址 | `MOV AX, [SI+10H]` | EA = SI + 10H |
| 基址变址 | `MOV AX, [BX+SI+10H]` | EA = BX + SI + 10H |

### Q153：简述8086标志寄存器各标志位的作用

**🔑 答案**：

| 标志位 | 名称 | 置1条件 |
|--------|------|---------|
| CF | 进位标志 | 最高位有进位/借位（无符号运算） |
| ZF | 零标志 | 运算结果为0 |
| SF | 符号标志 | 运算结果为负 |
| OF | 溢出标志 | 带符号运算溢出 |
| AF | 辅助进位 | D3→D4有进位/借位 |
| PF | 奇偶标志 | 低8位"1"的个数为偶数 |
| IF | 中断允许 | 置1允许可屏蔽中断 |
| DF | 方向标志 | 串操作方向（1=地址减量） |

### Q163：8086如何根据段基址和偏移地址计算物理地址？

**🔑 答案**：

8086有20位地址总线，可寻址1MB空间。16位段寄存器+16位偏移地址通过以下公式合成20位物理地址：

<div>
$$PA = (段基址) \times 16 + 偏移地址$$
</div>

或用十六进制：\(CS:IP = CS \times 10H + IP\)

例：CS=2000H, IP=100H → PA = 2000H × 10H + 100H = 20100H

### Q155/157：8086指令按功能可分为哪几类？

**🔑 答案**：

| 类别 | 示例 | 作用 |
|------|------|------|
| 数据传送 | MOV, PUSH, POP, XCHG | 数据搬移 |
| 算术运算 | ADD, SUB, MUL, DIV | 算术计算 |
| 逻辑运算 | AND, OR, NOT, XOR | 位操作 |
| 移位指令 | SHL, SHR, ROL, ROR | 逻辑/算术移位 |
| 串操作 | MOVSB, CMPSB, SCASB | 块数据操作 |
| 控制转移 | JMP, CALL, RET, Jcc, INT | 程序流程控制 |
| 处理器控制 | CLI, STI, NOP, HLT | CPU状态控制 |

### 本章小结

8086支持立即、寄存器、直接、间接、基址、变址、基址变址等多种寻址方式。标志寄存器有6个状态标志和3个控制标志。20位物理地址 = 段基址×16 + 偏移地址。
